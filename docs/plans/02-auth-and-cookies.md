# Specialist Plan 02: Authentication & Cookie Management (YouTube Premium)

## Objective
Provide a secure, reliable authentication mechanism for YouTube and YouTube Music within the Windows desktop app. This allows `yt-dlp` to access private playlists (Watch Later, Liked Music), bypass bot verification, and unlock **YouTube Premium high-bitrate audio streams (itag 141 - 256kbps AAC)**.

---

## 1. Why WebView2 Embedded Auth is Strictly Optional

1. **First-Class Guest / Unauthenticated Mode:**
   * The application operates completely out-of-the-box in anonymous Guest Mode without requiring any login, Google account, or cookies.
   * Standard public YouTube and YouTube Music videos, tracks, and playlists download seamlessly at standard quality (~128-160kbps).
2. **Opt-In YouTube Premium Escalation:**
   * Login is only needed when the user wishes to access private playlists (Watch Later, Liked Music) or unlock **YouTube Premium 256kbps AAC audio streams (itag 141)**.
3. **Chromium App-Bound Encryption:**
   * When the user chooses to log in, an embedded WebView2 modal bypasses Chromium 127+ App-Bound Encryption without requiring browser extensions or exposing Google passwords.

## 3. Cookie Extraction & Netscape Formatting

`yt-dlp` requires cookies passed via `--cookies <path>` in standard **Netscape HTTP Cookie File** format.

### 3.1 Extraction Logic
Using `Microsoft.Web.WebView2.Core.CoreWebView2CookieManager`:
```csharp
var cookieManager = webView.CoreWebView2.CookieManager;
var youtubeCookies = await cookieManager.GetCookiesAsync("https://www.youtube.com");
var googleCookies = await cookieManager.GetCookiesAsync("https://accounts.google.com");
```

### 3.2 Netscape File Spec
The generated cookie file must begin with:
```text
# Netscape HTTP Cookie File
# http://curl.haxx.se/rfc/cookie_spec.html
# This file was generated by YtDlpAudio. Do not edit.

.youtube.com	TRUE	/	TRUE	1775000000	SID	s_value...
.youtube.com	TRUE	/	TRUE	1775000000	HSID	h_value...
.youtube.com	TRUE	/	TRUE	1775000000	SSID	s_value...
.youtube.com	TRUE	/	TRUE	1775000000	APISID	a_value...
.youtube.com	TRUE	/	TRUE	1775000000	SAPISID	sa_value...
.youtube.com	TRUE	/	TRUE	1775000000	LOGIN_INFO	l_value...
.youtube.com	TRUE	/	TRUE	1775000000	PREF	f4=4000000
```
Tab-separated columns:
1. `domain` (prefixed with `.` if subdomains allowed)
2. `include_subdomains` (`TRUE` / `FALSE`)
3. `path` (`/`)
4. `secure` (`TRUE` / `FALSE`)
5. `expiration` (Unix epoch timestamp in seconds)
6. `name`
7. `value`

## 4. Encryption at Rest (DPAPI)

When persisting cookies between application sessions:
* The raw cookie text is encrypted via `System.Security.Cryptography.ProtectedData`:
  ```csharp
  byte[] rawBytes = Encoding.UTF8.GetBytes(netscapeContent);
  byte[] encryptedBytes = ProtectedData.Protect(
      rawBytes,
      optionalEntropy: null,
      scope: DataProtectionScope.CurrentUser
  );
  await File.WriteAllBytesAsync(encryptedCookiesPath, encryptedBytes);
  ```
* Only the logged-in Windows user account can decrypt this file.

## 5. YouTube Premium Detection Strategy

To display the Premium status badge in the UI:
1. **HTTP Probe:** Make an authenticated GET request to `https://www.youtube.com/paid_memberships` using the extracted cookie container.
2. **Payload Check:** Inspect the response HTML for the string `"YouTube Premium"` or `"membership_type":"PREMIUM"`.
3. **Format Probe (Fallback):** Run `yt-dlp` with `--dump-single-json` on a known YouTube Music track and check if format `141` (256kbps AAC) is listed in the formats array.
